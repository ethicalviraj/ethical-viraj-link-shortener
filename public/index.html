GET /api/shorten

Shorten any long URL into a compact link.

Parameters

ParamTypeRequiredDescription
urlstringYesThe long URL
apikeystringYesYour API key
tokenstringYesYour secret token

Example Request

GET https://ethical-viraj-link-shortener.vercel.app/api/shorten?url=https://example.com&apikey=virajdeveloper&token=VJ2026SECURE

Example Response

{
  "success": true,
  "shortUrl": "https://is.gd/abc123",
  "originalUrl": "https://example.com",
  "provider": "is.gd",
  "developer": "Viraj_Prajapati 👑"
}
