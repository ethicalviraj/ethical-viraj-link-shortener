API_KEY   = virajdeveloper

### 1️⃣ Shorten URL

**Endpoint:** `GET /api/shorten`

| Parameter | Type | Required | Description |
|:---------:|:----:|:--------:|:------------|
| `url` | `string` | ✅ | The long URL |
| `apikey` | `string` | ✅ | `virajdeveloper` |
| `token` | `string` | ✅ | `VJ2026SECURE` |

**Example:**

```bash
curl "https://ethical-viraj-link-shortener.vercel.app/api/shorten?url=https://example.com&apikey=virajdeveloper&token=VJ2026SECURE"
```

**Response:**

```json
{
  "success": true,
  "shortUrl": "https://is.gd/abc123",
  "originalUrl": "https://example.com",
  "provider": "is.gd",
  "developer": "Viraj_Prajapati 👑"
}
```
